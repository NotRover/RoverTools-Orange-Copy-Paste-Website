## Global shortcuts

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy as usual. The watcher captures it to history without any popup. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Capture the current selection to history and show the capture receipt popup. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Open the quick-paste popup at your cursor. |

Both popup hotkeys are toggles: pressing the combination again while the popup is open closes it. These three combinations are fixed and cannot be remapped. On native Wayland, where the app cannot grab global keys, bind the same two actions in your compositor instead. See the [Linux notes](/docs/linux/).

## Inside the paste popup

| Keys | Action |
|---|---|
| <kbd>1</kbd>-<kbd>9</kbd>, <kbd>0</kbd> | Paste the entry in that slot (while the search box is empty). |
| <kbd>Up</kbd> / <kbd>Down</kbd> | Navigate entries. |
| <kbd>Enter</kbd> | Paste the selected entry. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | Paste the selected entry and remove it from Recent. |
| <kbd>Tab</kbd> | Switch between Recent and Pinned. |
| <kbd>Space</kbd> | Toggle the preview panel (while the search box is empty). |
| <kbd>Esc</kbd> | Close the popup. |

## Inside the capture popup

The receipt shown after <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> takes these keys:

| Keys | Action |
|---|---|
| <kbd>P</kbd> | Pin the captured entry. |
| <kbd>S</kbd> | Save it. |
| <kbd>G</kbd> | Open the groups picker. |
| <kbd>Del</kbd> / <kbd>Backspace</kbd> | Delete it. |
| <kbd>Esc</kbd> | Close the popup, or the groups picker if it is open. |

## On clipboard cards

	<CardMenu spaces={2} x={12} y={12} />

| Input | Action |
|---|---|
| Click | Copy the entry back to the clipboard. Turn on *Click a card to view it* in Settings to open it on a single click instead. |
| Double-click | Open the entry in the full viewer (or copy it, if the setting above is on). |
| Right-click | Context menu: Copy, Pin, Save, Groups, Share, upload to or remove from cloud, View, and Delete. |
| Type chip | Expand or collapse a multi-file list. |
| +N chip | Show overflowing group tags. |

## Search and selection

| Keys | Action |
|---|---|
| Type in search | Filter as you type, matching content and group names. |
| <kbd>Esc</kbd> | Clear search, or exit selection mode. |
| <kbd>Enter</kbd> | Confirm a group add or rename. |
