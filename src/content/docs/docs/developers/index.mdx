Orange Copy Paste is open source under the AGPLv3. This section is for people who want to
read how it works, run their own sync backend, or contribute code.

The product is two halves that share one contract:

- **The desktop app** captures the clipboard, stores history and notes locally, holds every
  key, and does all encryption and decryption. It works fully offline; the cloud is optional.
- **The backend** is a stateless relay and store. It verifies Supabase-issued tokens, persists
  ciphertext it cannot read, fans changes out over WebSocket, and brokers blob storage.
