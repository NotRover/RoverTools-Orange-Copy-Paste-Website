In about five minutes you will install the app, copy three things, paste the second one by its number, and pin it so it stays. You need a Windows 10 or 11 PC or a Linux desktop, and a text editor such as Notepad to paste into. No account is needed.

## 1. Install the app

**On Windows:**

1. Open the [latest release](https://github.com/NotRover/RoverTools-Orange-Copy-Paste-App/releases/latest) and download the file ending in `-setup.exe`.
2. Run it. It installs for your user only, so it does not ask for admin rights.
3. Open **Orange Copy Paste** from the Start menu.

**On Linux:** download the `.deb`, `.rpm` or AppImage from the same release and install it the way you usually would. If you use Wayland rather than X11, set up the two hotkeys first by following [How to set up hotkeys on Wayland](/docs/linux/#how-to-set-up-hotkeys-on-wayland). Without that, step 3 below does nothing.

The app window opens on the clipboard screen, which is empty for now. An orange icon also appears in the system tray.

## 2. Copy three things

Open your text editor, type these three lines, and copy each one with <kbd>Ctrl</kbd>+<kbd>C</kbd>, one at a time:

```
Order 4471 shipped
meet@9:30, room B
https://example.com/invoice/4471
```

Look at the app window. The three entries are there, newest first.

## 3. Open the paste popup

Click on an empty line in your editor, then press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>.

A small popup opens at your cursor on its **Recent** tab. Your three entries are listed newest first, each with a number: `1` is the link, `2` is `meet@9:30, room B`, `3` is `Order 4471 shipped`.

If nothing opens, check that the tray icon is there, which means the app is running. On Wayland, check that your hotkeys are set up.

## 4. Paste by number

With the popup open, press <kbd>2</kbd>.

The popup closes and `meet@9:30, room B` is typed into your editor where the cursor was. You did not have to leave the editor or find the entry with the mouse.

## 5. Pin an entry

Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> again, hover over `Order 4471 shipped`, and click **Pin**. Then click the **Pinned** tab.

The entry is now on the **Pinned** tab, with its own number there. Pinned entries stay when you restart the app and when you use **Clear all**. Press <kbd>Esc</kbd> to close the popup.

## What you did

You used the app's main loop: copy as usual, press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>, and paste with one number key. Pinning is how you keep what you reach for every day.

Two defaults to know before you rely on it:

- **Unpinned history is cleared when the app restarts.** Turn on **Keep history across app restarts** in [Settings](/docs/settings/) to keep it.
- **Closing the window quits the app.** Turn on **Close to system tray** in Settings to keep it running in the tray instead.
