How the app checks for updates, what it installs and when, and where every release is published.

## Checking

<DocMock scale={1}>
	<UpdateCard />
</DocMock>

The app checks shortly after it starts and then every 6 hours, since it usually runs in the tray for weeks. A check is one small request and downloads nothing. Turn it off with **Check for updates automatically** in [Settings](/docs/settings/), and use **Check now** whenever you like.

## Installing

When a newer version is found, a banner offers it. Nothing is installed until you say so:

1. **Download** starts only when you press it, and shows progress.
2. **Restart & install** is a separate step, because it restarts the app. A download never takes the window from you mid-paste.
3. **Skip this version**, offered until you download, stops the banner for that version. The close button (**Remind me later**) hides the banner for now. Settings still offers a skipped version if you change your mind.

Every download is checked against a signing key built into the app before it installs. A file without a matching signature is refused, wherever it came from.

## Installing automatically

Turn on **Install updates automatically** in Settings and the app installs new versions itself, then reopens. It is off by default, and it only happens at startup, never while you are working:

- It runs from the startup notice, so **Show splash screen on startup** must stay on. With the splash off, updates are never installed automatically.
- **Check for updates automatically** must be on too; turning it off turns this off.
- A version you skipped is never installed automatically. It is only shown.

## Channels

- **Stable** (default): releases when they are ready.
- **Beta:** turn on **Get beta versions** in Settings to get new features early, alongside every normal release. Betas are tested less. Turning the switch off stops future betas, but it cannot move you back to an older version.

## Release notes

Every release ships notes written by a person, sorted into **New**, **Improved** and **Fixed**. They show in the update banner, in Settings, and on the [releases page](https://github.com/NotRover/RoverTools-Orange-Copy-Paste-App/releases), which is also where all installers are published.
