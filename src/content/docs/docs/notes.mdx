Notes live one click from your clipboard history and share its organizing model: the same pinning, groups, search, filters and bulk actions. Pinned notes rise to the top under their own header, and the list can show as tiles, a list, or a single column. Drag the divider to resize the list against the editor, or expand the editor to fill the window.

## The editor

A block-style editor with:

- Headings H1 to H5, bold, italic, underline, strikethrough, inline code.
- Bullet lists, ordered lists, and nested task lists with checkboxes.
- Blockquotes and callouts in five tones.
- Code blocks with syntax highlighting.
- Tables with per-cell backgrounds.
- Links with autolinking, images, horizontal rules.
- Text color, multicolor highlight, text alignment, and <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> indenting.

Notes auto-save while you type; there is no save button to forget, though <kbd>Ctrl</kbd>+<kbd>S</kbd> flushes the save immediately. A note you open and leave without a title or any content is discarded, so you never collect blank notes. The toolbar keeps a live word and character count and the time since the last edit, and <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> adjust the reading zoom.

## Clips inside notes

You can embed a clipboard entry or reference a group directly inside a note, so a note can collect the clips it is about.

## Attachments

Images and files dropped into a note are stored in the app's data folders and referenced from the note, keeping the note itself small and portable.

## Export

Any note exports as a `.md` file, or copies to the clipboard as Markdown. Export is a projection, not the storage format, so exporting changes nothing about the note.

## Syncing

With [cloud sync](/docs/cloud-sync/) on, notes sync end-to-end encrypted exactly like clipboard entries, and can be shared into [Spaces](/docs/spaces/). A note you share into a space stays yours: other members see it read-only, with a bar saying only you can edit it.
