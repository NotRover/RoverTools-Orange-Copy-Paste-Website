## The editor

A block-style editor with:

- Headings H1 to H5, bold, italic, underline, strikethrough, inline code.
- Bullet lists, ordered lists, and nested task lists with checkboxes.
- Blockquotes and callouts in five tones.
- Code blocks with syntax highlighting.
- Tables with per-cell backgrounds.
- Links with autolinking, images, horizontal rules.
- Text color, multicolor highlight, text alignment, and <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> indenting.

Notes auto-save while you type; there is no save button to forget.

## Clips inside notes

You can embed a clipboard entry or reference a group directly inside a note, so a note can collect the clips it is about.

## Attachments

Images and files dropped into a note are stored in the app's data folders and referenced from the note, keeping the note itself small and portable.

## Export

Any note exports as a `.md` file, or copies to the clipboard as Markdown. Export is a projection, not the storage format, so exporting changes nothing about the note.

## Syncing

With [cloud sync](/docs/cloud-sync/) on, notes sync end-to-end encrypted exactly like clipboard entries, and can be shared into [Spaces](/docs/spaces/).
